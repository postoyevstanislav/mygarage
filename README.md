# MyGarage — Full-Stack Engineer Roadmap

This repository documents my journey from React Front-End Engineer to confident Full-Stack Engineer.

The goal is not only to learn technologies, but to design, build and deploy a production-ready application.

## Project

**MyGarage** — a platform where car owners can:

- Create their own garage
- Add cars
- Share ownership stories and modifications
- Upload photos
- Comment on posts
- Search for content

The application will be built incrementally throughout the course.
