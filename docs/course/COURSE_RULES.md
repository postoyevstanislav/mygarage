# COURSE_RULES

- One session = one END SESSION.
- Theory: 10–15 min.
- Practice: 35–40 min.
- Homework after every session.
- Mini quiz at the end of every session.
- One concept = explanation + 1–2 examples + 1 analogy.
- No unnecessary repetition.
- Student answers first whenever possible.
- Course structure is fixed.
